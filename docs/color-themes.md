# Цветовые темы залов

Во всех четырёх залах используется исходная тема «Подвал» с ярким оранжевым акцентом `#ff653b`. После прохождения игры, при `state.won`, включается чёрно-золотая тема Босса Качалки.

Палитры определены в `dist/themes.css`, цвет браузера и автоматический выбор по прогрессу — в `dist/themes.mjs`. Исходные цвета сохранены в `dist/style.css`; переопределения фона, панелей, текста, границ и акцентов в `dist/themes.css` применяются только при `data-theme="boss"`. Зона успешного тайминга остаётся зелёной, ошибки и полученный урон сохраняют предупреждающий цвет.
