# GYM BOSS

Одиночная браузерная игра о пути от новичка до босса качалки. Четыре зала, 12 соперников, 3 тренировки с таймингом, тактическая борьба, магазин, усилители, достижения и финал. Прогресс и активная схватка сохраняются локально в текущем браузере.

## Запуск

`python3 -m http.server 4173 --directory dist`

Статическая версия без зависимостей и сборки. Состояние и экономика — `dist/engine.mjs`, интерфейс — `dist/app.mjs`. Для изображений использован встроенный imagegen; промпты сохранены в `image-prompts.json` и `image-prompts-extra.json`.

## Проверки

`node --check dist/app.mjs`

`node --check dist/engine.mjs`

`node tests/engine.test.mjs`

Симуляция кампании с подготовкой: 52 тренировки, 12 побед, без поражений. Расчётная длительность обычного первого прохождения — 20–30 минут; зависит от точности, чтения и покупок.

В браузере проверены тренировка из шести повторений, покупка, первый бой до награды, восстановление боя после reload, мобильная ширина390 без горизонтального переполнения, WebMCP чтение/навигация и отказ на неверных параметрах.
